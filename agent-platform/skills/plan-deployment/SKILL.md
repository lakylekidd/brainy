# Plan an Application Deployment

1. Search canonical knowledge for the application's deployment procedure.
2. Identify the requested release, environment, dependencies, and owner.
3. Read the documented health checks and rollback procedure.
4. Produce a proposed deployment plan with unresolved questions called out.
5. Use capability discovery to identify an authorized deployment skill and tools.

Planning does not grant deployment or secret access. Submit new observations as
memories or knowledge-change proposals through Brain APIs.
